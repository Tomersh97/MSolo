# MSolo
`MSolo` is a take on a solo old school MapleStory experience. Providing an immersive and intricate progression system for exlusive solo players.

## Modules
- `\src\main`: Server implementation java module.
- `\src\main\resources`: Resources used by the server.
- `\src\test`: Server testing module.
- `\scripts`: JavaScript execution scripts.
- `\handbook`: Indexed registry of in-game assets.
- `\wz`: .wz files of in-game assets. 
- `\tools`: Additional tools
